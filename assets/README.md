# ClipKit project assets

Add images, video, audio, JSON data, or source files here and select **Library → Rescan**. Media is registered when placed and copied into the project’s managed media directory. Sources are discovered for review and never automatically executed.

HTML/JSX/TSX need a frame-driven adapter with a declared schema. Install complete reviewed packs using `ck assets install PATH --trust` (trust only after reviewing executable code). Plain JSON is data, not an animation. Use a selected chart’s **Data JSON** control or the library’s Apply data action.

The example in sources/ is retained from the pinned MIT Anime.js source recorded in packages/assets/vendor/manifest.json. The editable adaptation is **Staggered tiles** in the application. Upstream notices remain in the original source tree.

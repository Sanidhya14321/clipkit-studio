# React Bits · Split Text

Characters or words animate as separately controlled objects.

Status: reference technique — adaptation required

## When to use

- A typographic phrase with spatial relationships and a shared destination.

## Avoid

- Every letter following the same spring throughout an entire film.

## Adapt to this video prompt

1. Split without changing copy semantics. Derive local progress from frame minus element delay; preserve layout metrics and explicit final poses.

Set the approved text, aspect ratio, brand palette, target frames, footage/narration and protected reading windows first. Choose this mechanism only when it expresses the shot’s purpose. Fast/slow pacing changes travel, density, accents and holds; never blindly speed up the whole scene.

## Implementation

Technique guidance. Author an original scene or a reviewed, appropriately licensed project-source adaptation; this entry is not an insertable component.

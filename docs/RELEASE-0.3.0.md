# 0.3.0 — agent-authored video editing and generation

The editor now turns a brief into original frame-driven scene code, publishes validated drafts to localhost, and lets a human revise controls/source or attach precise frame-range feedback. The rejected stock catalog is removed. Motion and Skills provide connected editorial techniques and selected Video Forge guidance; Media remains separate.

Longer productions can plan chapters and invoke an agent for one bounded chapter. Focused MCP profiles, compact affected-layer context, source line windows and timestamped transcript reads reduce unnecessary context loading. Actual provider usage and estimated incremental payload remain distinct.

## Artifacts

- `clipkit-studio-local-0.3.0.tgz`: local installation (`npm install /absolute/file.tgz`, then `ck init`, `ck studio`). No public npm package publication is implied.
- `clipkit-reel-0.3.0.mp4` and credits: 25-second vertical film with original sound and genuine editor evidence.
- `clipkit-workflow-0.3.0.mp4` and provenance: actual generation, feedback, human editing and export/download recordings.
- `clipkit-demo-project-0.3.0.tgz`: editable demo with immutable scene versions and history; extract, then `ck studio --root /absolute/extracted/folder`.
- `clipkit-compat-0.2.0.tgz`: optional fixed legacy renderer/resources/notices. Run `ck compat install /absolute/archive.tgz --root /old/project`, then restart. New projects do not need it.
- `verification-0.3.json`, motion source inventory and checksums.

Read [verification](VERIFICATION.md) before interpreting scope. Real Codex new-source authoring and local export are verified. Claude/Fish live acceptance and hour-long performance remain unverified.

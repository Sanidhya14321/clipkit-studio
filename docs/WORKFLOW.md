# Creative workflow

1. Write the brief: audience, purpose, exact copy, footage/narration, target duration, aspect and brand constraints.
2. Prepare. One resumable agent session sets the visual direction and chooses implementations only where useful, separates story/shot/copy timing, authors a real three-second proof and stops.
3. Review the storyboard, motion mechanisms, optional component versions and moving sample. Approve the exact version, edit the plan or request another direction. No timeout counts as approval.
4. Production resumes the exact session, preserves the approved opening and creates connected continuation. The accepted timeline remains unchanged.
5. Play the moving revision. Keep it as one undoable change, discard it, or request a bounded correction.

Exposed text/color/size/timing controls are local transactions without agent invocation. Choreography requests use one scoped invocation. Story redesign returns to the preparation checkpoint. No repeated regeneration loop runs unseen.

Range tool, I/O shortcuts and timecode controls create single-frame or interval anchors. At 30 fps, 5–10 seconds means [150,300). Saved bands restore the range. The server protects content outside the selection and maintains source phase across splits.

For long form, approve global narrative/style and chapter boundaries first. Produce one bounded chapter, retain its accepted version, then choose the next chapter. Load only affected chapter context and adjoining continuity.

A/B evaluation preserves the exact prompt, model/effort, dimensions, frame rate, original rhythm track and every measured attempt. Report elapsed time, calls, available actual usage and missing telemetry. Human preference is recorded separately from technical checks. Release quality cannot pass without the human preferring the new film over the plain-agent baseline.
